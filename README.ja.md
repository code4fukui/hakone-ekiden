# Hakone Ekiden 3Dビューワー

日本で有名な大学駅伝競走「箱根駅伝」のリアルタイム3Dデジタルマップです。本プロジェクトでは、レースコース全体を可視化し、ランナーの位置を追跡して、インタラクティブな3Dマップ上にチーム情報を表示します。

本リポジトリは、草薙 昭彦氏（[@nagix](https://twitter.com/nagix)）によるオリジナルの「箱根駅伝 3D」プロジェクトをベースにしています。オリジナル作品はこちらをご覧ください: [nagix.github.io/hakone-ekiden/](https://nagix.github.io/hakone-ekiden/)。

[ライブデモ](https://code4fukui.github.io/hakone-ekiden/)をご覧ください。

## 機能

- **リアルタイム3Dレースの可視化:** Mapbox GL JSを使用して、箱根駅伝の全コース（往路・復路）を3D地形マップ上にレンダリングします。
- **ランナーのライブトラッキング:** 各チームのランナーの位置を表示します。イベント中は10秒ごとにデータが自動更新されます。
- **アニメーション3Dモデル:** 各ランナーは、各大学のユニフォームのテクスチャが適用されたアニメーション3Dモデル（`runner.glb`）で表現されます。
- **複数のカメラ視点:** ドローン、ヘリコプター、一人称視点など、レースを追うための様々なトラッキングモードを切り替えることができます。
- **詳細なコース情報:** `data/sections.json`で定義されているチェックポイント、スタート/フィニッシュライン、中継所をポップアップで表示します。

## 仕組み

本アプリケーションは、ベースマップにMapbox GL JSを使用し、THREE.jsを統合してアニメーションする3Dランナーをカスタムレイヤーとしてレンダリングします。コース、チーム、標高データはローカルのJSONファイルから読み込まれます。レース中は、ランナーのライブ位置データを外部エンドポイントから取得します。

- **コースデータ:** `data/routes.json`には、レースルートの地理座標が含まれています。
- **チームデータ:** `data/teams.json`には、出場大学とエントリー選手一覧（2022年大会用）が記載されています。
- **チェックポイント:** `data/sections.json`には、公式の中継所が定義されています。
- **標高:** `data/distances.json`には、コースの標高プロファイルが提供されています。

## ローカルでの開発

本プロジェクトは静的なWebアプリケーションであり、ビルド手順やパッケージマネージャーは必要ありません。

1. リポジトリをクローンします:
    ```sh
    git clone https://github.com/code4fukui/hakone-ekiden.git
    ```
2. プロジェクトディレクトリに移動します:
    ```sh
    cd hakone-ekiden
    ```
3. ローカルWebサーバーを起動します。例えばPythonを使用する場合:
    ```sh
    python -m http.server
    ```
4. ブラウザを開き、`http://localhost:8000`（またはサーバーが使用しているポート）にアクセスします。
